데이터 삭제 안내

시행일: 2026년 5월 22일

냉장고 재료를 부탁해는 로그인 없이 사용할 수 있는 앱입니다.

1. 앱 안에서 삭제할 수 있는 데이터

사용자는 앱 안에서 냉장고 재료, 유통기한, 보관 위치, 수량, 메모, 장보기 목록 등을 직접 수정하거나 삭제할 수 있습니다.

2. 서버에 저장된 데이터 삭제 요청

사용자가 동기화 또는 요청 기능을 사용하여 서버에 저장된 데이터가 있는 경우, Google Play 스토어에 등록된 개발자 연락처를 통해 삭제를 요청할 수 있습니다.

3. 삭제되는 데이터

  • 사용자가 입력한 냉장고 재료 및 장보기 데이터
  • 사용자가 요청한 서버 저장 데이터
  • 사용자가 직접 작성한 메모 및 앱 사용 데이터 중 식별 가능한 항목

4. 삭제되지 않을 수 있는 데이터

법적 의무 이행, 보안, 부정 사용 방지, 서비스 품질 개선을 위해 필요한 최소한의 비식별 로그는 일정 기간 보관될 수 있습니다.

5. 처리 기간

삭제 요청은 접수 후 합리적인 기간 내에 처리합니다.
