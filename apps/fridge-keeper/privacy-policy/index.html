개인정보처리방침

시행일: 2026년 5월 22일

냉장고 재료를 부탁해(이하 “앱”)는 로그인 없이 사용할 수 있는 냉장고 재료 및 장보기 관리 앱입니다. 앱은 이용자의 개인정보와 입력 데이터를 안전하게 처리하기 위해 아래와 같이 개인정보처리방침을 공개합니다.

1. 수집 및 저장하는 데이터

앱은 기능 제공을 위해 다음 정보를 저장하거나 처리할 수 있습니다.

  • 사용자가 직접 입력한 냉장고 재료명, 유통기한 또는 보관기간, 보관 위치, 수량, 메모
  • 사용자가 직접 입력하거나 관리하는 장보기 목록
  • 레시피, 통계, 사용성 개선을 위해 앱 내부에서 생성되는 데이터
  • 사용자가 동기화 또는 요청 버튼을 실행할 때 서버에 저장되는 데이터
  • 광고 제공을 위해 Google AdMob이 처리할 수 있는 광고 ID, 기기 정보 등

앱은 별도의 회원가입이나 로그인 계정을 제공하지 않습니다.

2. 데이터 이용 목적

수집 또는 저장되는 데이터는 다음 목적에 사용됩니다.

  • 냉장고 재료 관리 기능 제공
  • 장보기 목록 관리 기능 제공
  • 보관기간 알림, 통계, 요리 추천 등 앱 기능 제공
  • 사용자가 요청한 데이터 동기화 또는 요청 처리
  • 오류 수정 및 서비스 품질 개선
  • 무료 버전 광고 제공

3. 제3자 서비스

앱은 다음 외부 서비스를 사용할 수 있습니다.

  • Supabase: 사용자가 요청한 데이터 저장 및 동기화 처리
  • Google AdMob: 광고 제공

Google AdMob은 광고 제공을 위해 광고 ID, 기기 정보 등 일부 정보를 처리할 수 있으며, 이 항목은 Google의 광고 및 개인정보 처리 정책을 따릅니다.

4. 데이터 보관 기간

사용자가 앱에서 데이터를 삭제하거나 삭제 요청을 하기 전까지 데이터가 보관될 수 있습니다. 동기화된 데이터도 사용자의 삭제 요청이 있을 경우 처리됩니다.

5. 사용자 권리

사용자는 앱 안에서 입력한 데이터를 수정하거나 삭제할 수 있습니다. 서버에 저장된 데이터 삭제가 필요한 경우 앱 내 문의 기능 또는 Google Play 스토어에 등록된 개발자 연락처를 통해 요청할 수 있습니다.

6. 정책 변경

개인정보처리방침이 변경될 경우 이 페이지를 통해 안내합니다.
